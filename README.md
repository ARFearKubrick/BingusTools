# Bingus Tools

The identity editor and the Animator for **Bingus**, a Limbus Company PvP fan game, in one program.

- **Identity editor:** edit an identity or E.G.O (stats, skills, coins, passives, effects, statuses and images) on a card that looks like the in-game one. Effects are checked as you type.
- **Animator:** edit the animations of an identity (`sprites.json`): poses, keyframes, particles, sounds and camera.

## Download

**[BingusTools_v1.zip](https://github.com/ARFearKubrick/BingusTools/releases/download/v1/BingusTools_v1.zip)** (about 820 MB). All versions are listed on the [Releases](https://github.com/ARFearKubrick/BingusTools/releases) page.

Windows 10/11 (64-bit). You don't need to install anything else.

## How to use it

1. Extract the zip anywhere. You get a `Bingus` folder.
2. Open `Bingus\BingusTools.exe`. It takes a few seconds to get ready the first time.
3. When it asks for the data folder, choose that same `Bingus` folder (the one with `Identities` and `EGO` inside).
4. To open the Animator, use the **Open Animator** button in the editor.

The zip includes the identities and E.G.O of the twelve Sinners, and a `TEMPLATE` of each to start new ones from.

Windows may warn you the first time because the program isn't signed. To open it anyway, click **More info → Run anyway**.

## Language

The first time, the tools use the language of Windows (Spanish or English). To switch, use the **EN/ES** button in the editor's toolbar, or **View → Español / English** in the Animator. Both tools share the setting.
